# AutoTurn VPN 1.7.0

Первый публичный релиз после **1.5.0**. Версия 1.6.0 использовалась только для
локального тестирования. Ниже перечислены все изменения относительно 1.5.0.

## Что нового

- **Защищённый режим.** Новая опция в настройках сохраняет блокирующий VPN-интерфейс
  при обрыве соединения, смене профиля и недоступности всех серверов. Поддерживает
  AWG, VLESS/Reality, Hysteria 2 и qWDTT, а также все три режима выбора приложений.
  По умолчанию выключен, в том числе после обновления с 1.5.0.
- **Включение и отключение профилей.** Переключатель и подпись показывают, разрешено
  ли подключение. Отключённый профиль сохраняет конфигурацию, роль и место в очереди,
  но пропускается при подключении. Если основной отключён, используется первый
  разрешённый резерв.
- **Перезапуск очереди с главного экрана.** Кнопка «Начать очередь заново» прерывает
  текущую попытку и начинает с основного разрешённого профиля. Работающий режим
  Авто сохраняется; из выключенного состояния кнопка включает VPN вручную.
- **Сохранение IP серверов.** При повторном подключении используется уже известный
  IP. Домены проверяются в фоне и дополнительно после отказа соединения; изменение
  IP не разрывает работающий VPN. Исходный домен, SNI, сертификаты и ключи профиля
  сохраняются. Механизм работает в обычном и защищённом режимах.
- **Служебный DNS для запуска VPN и qWDTT.** Адреса серверов и служебные имена
  VK/TURN разрешаются через DNS текущей сети. При смене Wi-Fi/мобильной сети qWDTT
  получает актуальные адреса DNS. Это отдельный служебный путь: DNS выбранных
  приложений в защищённом режиме остаётся внутри VPN.
- **Более устойчивый контроль соединения.** Перед сменой профиля неудачная короткая
  проверка подтверждается дополнительными запросами. Ошибка отдельного сайта
  не считается отказом всего туннеля. Первая неудачная проба сохраняет соединение
  и показывает перепроверку. Исправлено сохранение старой надписи «Нет сети» после
  восстановления сети и распознавание мобильной сети без пригодного IP-адреса.
- **Стабильность переключений.** Улучшены остановка и смена движков в защищённом
  режиме, обработка запоздавших ответов предыдущей попытки и освобождение AWG.

## Обновление с 1.5.0

Устанавливайте **поверх существующего приложения**, без удаления. Сохраняются
профили, их порядок, основной профиль, домашние Wi-Fi, режимы и списки приложений.
Все существующие профили после обновления разрешены к подключению. Защищённый
режим автоматически не включается. APK подписан прежним ключом.

Автообновление доступно через обычную проверку приложения. Автоматическая
проверка выполняется при открытии не чаще раза в сутки; немедленную проверку
можно запустить вручную в настройках. Установку подтверждает пользователь Android.

## Поведение защищённого режима

Ручное выключение VPN вне домашней сети останавливает транспорт, сохраняя блокировку.
Для прямого доступа отключите защищённый режим. В домашней сети автоматическое
выключение VPN сохраняет прежнее поведение. Обычный режим остаётся доступным.

Защищённый режим не заменяет системную блокировку при принудительной остановке
приложения, отзыве VPN-разрешения и до первоначального создания VPN после загрузки
телефона. Системные Always-on/«Блокировать без VPN» автоматически не включаются.

Для первого подключения к новому домену нужен доступный DNS, а для qWDTT — доступ
к необходимым API и relay VK. Сохранённый IP VPS не отменяет получение TURN-сессии.
Таймауты запуска qWDTT и капчи в этом обновлении не сокращались.
