# Скриншоты документации

[← Обзор](../README.md) · [Инструкция](usage.md)

Все кадры сняты с Android-приложения на POCO F7. Изображения сохранены без изменения интерфейса. Новые кадры взяты из локальных материалов прежних проверок; исходные тестовые материалы не нужны для чтения инструкции.

| Файл | Версия | Что показывает |
| --- | --- | --- |
| [vpn-modes.png](images/vpn-modes.png) | 1.0.5 | Три режима управления |
| [auto-return-dark.png](images/auto-return-dark.png) | 1.0.5 | Срок возврата в Авто, тёмная тема |
| [auto-return-light.png](images/auto-return-light.png) | 1.0.5 | Срок возврата в Авто, светлая тема |
| [app-routing.png](images/app-routing.png) | 0.4.1 | Исключение приложений из VPN, поиск и сохранение |
| [settings-light.png](images/settings-light.png) | 0.5.0 | Тема, домашний Wi-Fi и переход к приложениям |
| [update-home.png](images/update-home.png) | 1.0.10 | Доступное обновление до 1.0.11 на главном экране |

Названия приложения и действий в инструкции сверены с исходниками 1.0.11. Исторический кадр не подтверждает, что вся показанная версия прошла новую проверку.

При обновлении документации снимайте реальные экраны с демонстрационными профилями и нейтральным именем сети. Не показывайте ключи, адрес сервера, UUID, пароль, QR-коды и личные уведомления. Подписывайте версию и устройство; не выдавайте макет за скриншот.
