# Данные и разрешения

[← Обзор](../README.md) · [Инструкция](usage.md)

Описание относится к Android-клиенту AutoTurn 1.0.11. Серверная панель и Telegram-прокси — отдельные компоненты с отдельным хранением данных.

## На устройстве

AutoTurn хранит VPN-профили, имя домашнего Wi-Fi, выбранные приложения, режим, тему и таймер возврата локально. Настройки шифруются AES-GCM; ключ создаётся в Android Keystore. Android-резервное копирование данных приложения отключено в манифесте.

Параметры обновлений и служебное состояние также сохраняются локально. Шифрование профиля защищает сохранённый файл, но не заменяет защиту самого телефона. Удаление приложения или очистка его данных удаляет настройки и может сделать локальные профили невосстановимыми. Сохраняйте исходные конфигурации отдельно.

## Разрешения

| Доступ | Для чего нужен |
| --- | --- |
| Точное местоположение | Чтение имени подключённого Wi-Fi для определения домашней сети |
| Местоположение «Всегда» | То же определение при закрытом приложении |
| VPN | Создание выбранного пользователем туннеля через Android VpnService |
| Уведомления и foreground-служба | Отображение и поддержание фоновой автоматизации и туннеля |
| Список установленных приложений | Выбор приложений, которые используют VPN или обычную сеть |
| Установка APK из AutoTurn | Передача скачанного обновления установщику после действия пользователя |
| Запуск после загрузки | Возобновление включённого управления после перезагрузки |
| Wake lock | Поддержание активного Xray-туннеля при выключенном экране |

Координаты не читаются: разрешение местоположения требуется Android для доступа к SSID. Список приложений используется для локальной маршрутизации. Импорт файла проходит через системный выбор документа; ссылка читается из буфера обмена при нажатии **«Вставить ссылку»**.

## Сетевые запросы

- VPN-трафик направляется на сервер выбранного профиля. Оператор этого сервера и провайдеры по пути имеют обычную для такого соединения видимость трафика.
- При включённом контроле соединения выполняются HTTPS-проверки `example.com` и `www.wikipedia.org` через VPN. Эти сервисы получают запрос и видимый им IP-адрес.
- Проверка обновлений обращается к публичному GitHub API и загрузке вложений Releases. GitHub получает сетевой запрос, IP-адрес и обычные метаданные HTTP. Токен GitHub приложению не нужен.
- Xray использует DNS и другие параметры, заданные конфигурацией и логикой туннеля. Пользовательский JSON может содержать собственные сетевые назначения.

В Android-клиенте нет отдельного сервиса аккаунтов, аналитического SDK или отправки профилей в серверную панель. Это не означает, что VPN-сервер, DNS и внешние сервисы не видят обращений к ним.

## Что публиковать при обращении за помощью

Достаточно версии приложения, телефона, Android, типа протокола, режима и шагов воспроизведения. Не прикладывайте приватные ключи, UUID, пароль, полный профиль, ссылку подключения или QR-код. Проверьте скриншоты и журналы перед отправкой. Об уязвимости сообщайте по [SECURITY.md](../SECURITY.md).
