# AutoTurn VPN 2.0.1

Небольшое обновление. Ставится поверх: профили, домашние сети и настройки сохраняются.

**Обновления приходят быстрее**
- Раньше AutoTurn проверял новые версии при открытии не чаще раза в сутки. Если версия выходила днём, её было видно только на следующий день.
- Теперь проверка идёт при открытии или разворачивании приложения, если с прошлой прошло больше часа.
- В фоне приложение ничего не проверяет, поэтому на батарею это не влияет.
- Кнопка **Настройки → Проверить обновления** по-прежнему работает в любой момент.

Нужен Android 12 или новее.
