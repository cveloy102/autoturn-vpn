# Проверка AutoTurn 1.0.8

На POCO F7 с Android 16 / HyperOS итоговый прогон завершился успешно: **46 тестов**, 110,91 с.

Проверены:

- метаданные GitHub Release, недопустимые URL, черновики, предварительные релизы, размеры и хеши;
- принятие более новой APK с прежним ключом, отклонение другой подписи, другого пакета, текущей/старой версии и повреждённого APK;
- ручная проверка, суточный интервал, жизненный цикл Activity, сохранение прокрутки и стандартное открытие APK средствами Android;
- модель управления, настройки, плитка, темы и интерфейс;
- три подключения AmneziaWG и десять Hysteria 2 с реальным HTTPS-трафиком.

Отдельно проверены скачивание из публичного релиза, отмена, повторное скачивание, фон, сохранение скачанного обновления после перезапуска процесса и настоящая установка через штатный Android-установщик. Проведены повторные прогоны. Зашифрованные пользовательские настройки после проверок совпали с исходными побайтно.

Проверки находятся в `app/src/androidTest/`. Нативные проверки APK требуют временных APK с большей версией, подписанных оригинальным и альтернативным тестовым ключами, в `/data/local/tmp/autoturn-update-candidate.apk` и `/data/local/tmp/autoturn-wrong-signature.apk`. Проверки установщика требуют разрешения Android на установку из AutoTurn. Проверки настоящих VPN требуют тестового устройства с рабочими профилями. Не запускайте полный набор на случайном устройстве: он переключает подключения.

OnePlus 15 физически не проверялся. Проверена одна общая APK; система сама выбирает способ открытия APK. Временные тестовые сборки и ключи в публичные релизы не включаются.
