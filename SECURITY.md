# Сообщить об уязвимости

Для обычных ошибок используйте [Issues](https://github.com/cveloy102/autoturn-vpn/issues/new/choose). Для уязвимости не публикуйте ключи, конфигурации, адреса личных серверов или рабочий способ доступа к ним.

Если в разделе **Security** репозитория доступна кнопка **Report a vulnerability**, отправьте приватное сообщение через неё. Если приватная форма недоступна, откройте Issue только с просьбой предоставить приватный канал, без технических деталей, секретов и воспроизводимого эксплойта.

В приватном сообщении укажите затронутую версию, компонент, условия воспроизведения и возможное влияние. Используйте демонстрационные данные. Для первичной проверки ориентируйтесь на последнюю опубликованную Android-версию; сроки ответа и поддержки старых версий пока не установлены.

Профили шифруются на устройстве с Android Keystore. Обновления проверяют хеш, пакет, версию и подпись APK. Не обходите эти проверки для установки неизвестного файла. Описание данных и сетевых запросов: [PRIVACY.md](docs/PRIVACY.md).
