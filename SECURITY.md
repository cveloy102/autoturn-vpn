# Безопасность AutoTurn

## Как сообщить об уязвимости

**Не публикуйте действующие VPN-ключи, токены, конфигурации, пароли или детали эксплуатации ещё не исправленной уязвимости в открытых Issues.** Для чувствительных сообщений используйте [GitHub Security Advisories — Report a vulnerability](https://github.com/cveloy102/autoturn-vpn/security/advisories/new), если функция включена владельцем репозитория. Если она недоступна, свяжитесь с владельцем через доступный приватный канал вместо публикации секрета.

В сообщении полезны: версия AutoTurn и Android, краткое описание влияния, условия воспроизведения и обезличенные доказательства. Не проводите тестирование чужих серверов без разрешения.

## Установка и обновления

Официальный канал загрузки APK — [GitHub Releases](https://github.com/cveloy102/autoturn-vpn/releases). Не рекомендуется устанавливать пересобранные APK из неизвестных источников. Встроенная процедура обновления проверяет SHA-256, имя пакета, версию и прежнюю подпись Android перед передачей файла установщику; пользователь подтверждает установку.

CI-сборки используют стандартный debug-ключ среды выполнения и **не должны** использоваться для обновления официально подписанной версии: это может привести к конфликту подписей и потере данных при удалении приложения.

## Компоненты

Информация о включённых библиотеках: [Xray](app/libs/ORIGIN.md) и [AmneziaWG](third_party/amneziawg-tunnel/ORIGIN.md). Сообщения о проблемах в сторонних компонентах также следует адресовать соответствующим upstream-проектам.
