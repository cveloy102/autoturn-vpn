# AutoTurn VPN

**VPN, который подстраивается под вашу сеть.** AutoTurn включает подключение вне домашнего Wi-Fi и выключает его дома. Ручное управление остаётся доступным в приложении и в шторке Android.

**Android 10+ · версия 1.0.11 · AmneziaWG / VLESS / Hysteria 2**

## Возможности

| Возможность | Как работает |
| --- | --- |
| Автоматизация по Wi-Fi | В режиме «Авто» домашняя сеть отключает VPN; вне неё подключение включается. |
| Ручной контроль | «Включён вручную» и «Выключен» имеют приоритет над автоматикой. |
| Возврат в Авто | После ручной команды можно вернуться к автоматике через 2, 4, 6 или 24 часа. Таймер можно отключить. |
| Несколько профилей | Импорт, выбор, переименование и удаление профилей; одновременно работает один туннель. |
| Резервное подключение | Проверка реального доступа через VPN и переход к другому профилю при недоступности. |
| Выбор приложений | Весь трафик, только выбранные приложения или все, кроме выбранных. |
| Плитка в шторке | Быстрое включение и выключение VPN с отображением типа подключения. |
| Оформление | Тёмная, светлая и системная темы. |
| Обновления | Проверка GitHub Releases раз в сутки и вручную; найденное обновление доступно по кнопке на главном экране, установка с подтверждением Android. |

Поддерживается импорт AmneziaWG `.conf`, ссылок VLESS + REALITY и Hysteria 2, а также конфигураций Xray `.json`. Профили и настройки хранятся на устройстве в зашифрованном виде.

## Начало работы

1. Скачайте APK из публичного релиза и установите на телефон. Вход в GitHub не требуется.
2. В разделе **Профили** импортируйте конфигурацию вашего VPN-сервера и выберите подключение.
3. Подключитесь к домашнему Wi-Fi и выберите текущую сеть в **Настройках**.
4. Выберите режим **Авто** и подтвердите системный запрос Android на VPN-подключение.
5. При необходимости настройте приложения, резервные профили и срок возврата после ручной команды.

AutoTurn — клиент: для работы нужен собственный сервер или выданный вам профиль. Приложение не предоставляет VPN-подписку.

## Режимы подключения

| Режим | Дома | Вне дома |
| --- | --- | --- |
| Авто | VPN выключен | VPN включён |
| Включён вручную | VPN включён | VPN включён |
| Выключен | VPN выключен | VPN выключен |

Новая ручная команда запускает отсчёт возврата заново. Выбор «Авто» отменяет таймер. В ручном режиме приложение показывает запланированное время возврата.

## Совместимость

Проверено на POCO F7 с Android 16. Android допускает одно активное VPN-подключение одновременно. Энергосбережение может задерживать таймеры; поддержание активного туннеля также расходует батарею. Контроль соединения зависит от доступности проверочных HTTPS-адресов.

## В версии 1.0.11

- При открытии приложение предлагает только доступное обновление. Сохранённый результат ручной проверки больше не показывается повторно.
- Проверка обновлений при открытии приложения, максимум раз в 24 часа.
- Кнопка «Проверить обновления» проверяет сразу, независимо от суточного интервала.
- Системное скачивание APK, проверка SHA256, имени пакета, версии и прежней подписи.
- Android запрашивает разрешение на установку обновлений и подтверждение установки. Профили и настройки сохраняются.
