## Один пульт для повседневного VPN

Добавьте профиль и выберите домашнюю сеть. В режиме **«Авто»** AutoTurn выключает VPN дома и включает его в другой Wi-Fi или мобильной сети. Кнопка на главном экране и плитка в шторке позволяют управлять подключением вручную.

| Возможность | Как работает |
| --- | --- |
| Домашний Wi-Fi | Одна домашняя сеть по имени SSID, автоматическое переключение |
| Три протокола | AmneziaWG `.conf`, VLESS + REALITY по TCP, Hysteria 2 |
| Несколько профилей | Выбор, переименование, удаление и резерв по порядку |
| Контроль соединения | Проверка HTTPS через VPN и переход к резерву при сбое |
| Приложения в VPN | Все, только выбранные или все, кроме выбранных |
| Ручные режимы | «Включён вручную» и «Выключен» имеют приоритет над автоматикой |
| Возврат в Авто | Через 2, 4, 6 или 24 часа; можно отключить |
| Оформление | Тёмная, светлая и системная темы |
| Обновления | GitHub Releases, проверка APK и установка с подтверждением Android |

AutoTurn использует **ваш VPN-сервер или выданный вам профиль**. Приложение не предоставляет сервер или VPN-подписку.

## Установка за несколько шагов

1. Откройте [последний релиз](https://github.com/cveloy102/autoturn-vpn/releases/latest), раскройте **Assets** и скачайте `AutoTurn-<версия>.apk`.
2. Установите APK и откройте AutoTurn. Android может запросить разрешение на установку из браузера или файлового менеджера.
3. В **Профилях** нажмите **«+ Добавить профиль»** для файла или **«Вставить ссылку»** для ссылки из буфера обмена.
4. Подключитесь к домашнему Wi-Fi. В **Настройках** нажмите **«Выбрать текущую сеть»** и разрешите точное местоположение для чтения имени Wi-Fi.
5. Выберите **«Авто»**, разрешите доступ к местоположению **«Всегда»** для фонового переключения и подтвердите системный запрос VPN.

**Требуется Android 10 или новее.** Проверено на POCO F7 с Android 16 / HyperOS. Вход в GitHub для скачивания не нужен.

[Подробная инструкция и первая проверка →](docs/usage.md#первый-запуск)

## Через VPN — нужные приложения

В **Настройках → Настроить приложения** выберите весь трафик, только выбранные приложения или исключения. Остальные приложения в выборочном режиме используют обычную сеть. Сохраните выбор кнопкой внизу экрана.

На Android маршрутизация задаётся **по приложениям**. [Как настроить её и учесть системную блокировку без VPN →](docs/usage.md#приложения-в-vpn)

## Управление, которое можно переопределить

| Режим | Дома | Вне дома |
| --- | --- | --- |
| Авто | VPN выключен | VPN включён |
| Включён вручную | VPN включён | VPN включён |
| Выключен | VPN выключен | VPN выключен |

После ручной команды таймер может вернуть управление автоматике. Новая команда начинает отсчёт заново; выбор «Авто» отменяет таймер. Плитка в шторке переключает ручное включение и выключение; длинное нажатие открывает приложение.

[Режимы, таймер и плитка →](docs/usage.md#режимы-и-возврат-в-авто)

## Обновления с сохранением настроек

В **Настройках** нажмите **«Проверить обновления»**. Доступная версия также появляется кнопкой на главном экране. Скачайте её и подтвердите установку Android: профили и настройки сохранятся при обновлении APK с прежней подписью.

Проверка при открытии выполняется максимум раз в сутки; ручная проверка доступна сразу. Перед установкой проверяются SHA-256, пакет, версия и подпись APK.

[Обновление и решение ошибок установки →](docs/usage.md#обновление)

## В составе репозитория

`app/` — Android-клиент; `third_party/` — туннель AmneziaWG; `admin-panel/` — серверная панель; `site/` — исходники сайта. Для использования APK разворачивать панель и сайт не требуется. [Панель](admin-panel/README.md) и [Telegram-прокси](admin-panel/relay/README.md) документированы отдельно.

Происхождение и лицензии библиотек: [Xray](app/libs/ORIGIN.md), [AmneziaWG](third_party/amneziawg-tunnel/ORIGIN.md), [все компоненты](docs/THIRD_PARTY.md).

[AutoTurn для macOS](https://github.com/cveloy102/autoturn-macos) — отдельный AmneziaWG-клиент для Intel и Apple Silicon со своим каналом обновлений.
