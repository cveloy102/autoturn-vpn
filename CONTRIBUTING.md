# Участие в разработке AutoTurn

Спасибо за интерес к AutoTurn для Android. Прежде чем отправить изменение, посмотрите [инструкцию по сборке](docs/DEVELOPMENT.md) и [текущие issues](https://github.com/cveloy102/autoturn-vpn/issues).

## Об ошибках

Используйте [шаблон багрепорта](https://github.com/cveloy102/autoturn-vpn/issues/new/choose). Напишите версию приложения, модель и Android, используемый протокол, режим и шаги воспроизведения. Для проблем с сетью укажите, возникает ли ошибка на Wi-Fi, мобильном интернете или в обеих сетях.

**Не публикуйте приватные ключи, конфигурации целиком, пароли, токены, личные IP и идентификаторы устройств.** Удаляйте секреты из логов и изображений.

## Предложение изменений

1. До большой доработки откройте issue и опишите сценарий пользователя.
2. Делайте небольшие тематические pull requests без попутного рефакторинга.
3. Если меняется UI, приложите скриншоты без настоящих ключей и персональных серверов.
4. Если меняется VPN-поведение, отдельно проверьте подключение/отключение, переход Wi-Fi ↔ мобильная сеть и ручной режим.
5. Выполните `./gradlew :app:assembleDebug :app:lintDebug` (Windows: `gradlew.bat`). Укажите результат в PR.
6. Обновите README, руководство и CHANGELOG, если изменилось поведение пользователя.

## Выпуск приложения

Pull request и CI-артефакт не являются официальным релизом. Публикация требует прежнего закрытого ключа подписи, тестирования на устройстве и отдельного GitHub Release. См. [процедуру выпуска](docs/DEVELOPMENT.md).

## Лицензия

Перед использованием чужих фрагментов кода, распространением модификаций или добавлением новых зависимостей уточняйте лицензии. Публичность репозитория не означает автоматического разрешения на переиспользование кода. Лицензии включённых сторонних компонентов рассматриваются отдельно.
